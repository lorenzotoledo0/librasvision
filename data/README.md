# data/

Esta pasta guarda os dados do projeto: vídeos, landmarks, manifesto, cadastro de sinalizadores, splits e auditoria. Ela é criada e preenchida pelos aplicativos e scripts.

**Nada aqui vai para o Git**, exceto este arquivo. São dados de pessoas, protegidos pela LGPD. Veja [docs/DATA_PRIVACY.md](../docs/DATA_PRIVACY.md).

A estrutura esperada e as convenções de nomes estão em [docs/DATASET.md](../docs/DATASET.md).

Não sincronize esta pasta com serviços de nuvem pessoais.
