# ADR 0001: Python 3.11

- Situação: aceita
- Data: 2026-10-05
- Detalhes: [decisoes.md, D1](../decisoes.md#d1-ambiente-e-versões)

## Contexto

As máquinas da equipe têm Python 3.14. O projeto depende de TensorFlow e MediaPipe, que publicam pacotes binários (wheels) para um conjunto limitado de versões do Python. Em 2026-10-05, a equipe verificou que nenhum dos dois tinha pacote para 3.14 e que o MediaPipe 0.10.21 declara suporte a 3.9 até 3.11 no PyPI.

## Decisão

Usar Python 3.11 em um ambiente virtual próprio (`py -3.11 -m venv .venv` no Windows). O 3.11 convive com o 3.14 já instalado. O pacote avisa, ao ser importado, quando a versão está fora da faixa 3.10 a 3.12. Só o 3.11 é testado.

## Consequências

- A instalação exige baixar o Python 3.11 à parte (documentado no README e em `instalar.bat`).
- Migrar para um Python mais novo depende de TensorFlow e MediaPipe publicarem pacotes compatíveis e de uma nova verificação conjunta (`pip check`).
