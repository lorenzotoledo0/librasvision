# Suporte

- **Dúvidas de uso e ideias:** abra uma discussão na aba [Discussions](https://github.com/lorenzotoledo0/librasvision/discussions).
- **Erros:** abra uma issue com o modelo "Relato de erro". Anexe `runs/logs/app.log` (e `runs/logs/falhas_nativas.log`, se existir). Esses logs usam só IDs anônimos, mas confira antes de enviar.
- **Segurança e privacidade:** siga o [SECURITY.md](SECURITY.md). Não use issues públicas.
- **Perguntas frequentes:** [docs/FAQ.md](docs/FAQ.md).

Este é um projeto acadêmico (TCC). O suporte é feito pela equipe no tempo disponível, sem garantia de prazo.
